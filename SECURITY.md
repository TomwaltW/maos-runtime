# Security Policy

## Supported versions

Only the latest commit on `main` is supported during the MVP phase.

## Reporting a vulnerability

Do not publish proof-of-concept details, credentials, customer data, or unredacted logs in a public issue. Contact the repository owner privately with a concise impact description, affected commit, reproduction steps, and sanitized evidence. The maintainer will acknowledge the report, assess impact, and coordinate remediation before public disclosure.

This MVP intentionally has no production credentials, external payment calls, or live tool adapters. Reports that identify a boundary escape, unintended write, authorization bypass, or sensitive-data exposure are especially valuable.
