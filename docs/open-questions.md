## 🟡 「转录待核」是什么意思 —— 先读这段再往下看

T 轮（2026-08-29）编排侧从**一张规则图**里转录出了一批口径，填进了下面两条。
**这不等于「答了」。** 转录件与官方原文的区别，在这份文件里是硬区别：

| | 官方原文 | 转录件（现在填进来的这些） |
| :-- | :-- | :-- |
| 来源 | 复赛官方通知 / 投稿要求页 | 编排侧对一张规则图的**人工转录**，二手 |
| 能不能当判据 | 能 | **不能** |
| 出错会怎样 | —— | 形式审查一票驳回，而这是**最贵的一类返工** |

**已经有一处证据表明转录件不可尽信**：OQ-1 原本问的是「评审**四维**」，
而转录出来是**五维**（20/25/20/30/5，合计 100%）。**问题的前提本身就写错过一次。**

所以：**每一条转录值都标着 🟡，用它做的决定都必须留退路，人类核实前不许当成定论。**
本文件抬头那条 Z-4 约束（「不许猜」）**没有被放宽** —— 转录不是猜，但转录**也不是答**。
